# 🚀 Raj Maheshwari | Developer Portfolio

Welcome to my personal developer portfolio! This project is a dynamic, high-performance web application built to showcase my skills, projects, and coding activity in real-time.

## ✨ Features

- **Interactive 3D Graphics**: Integrates `Three.js` for stunning, interactive background elements and modern visual appeal.
- **Live GitHub Integration**: Automatically fetches and displays real-time GitHub activity, repositories, and top languages used.
- **Live LeetCode Stats**: Pulls live data from LeetCode to display problem-solving statistics and coding consistency.
- **Modern UI/UX**: Designed with a clean, responsive layout featuring glassmorphism and smooth CSS animations.
- **Dynamic Caching**: The backend implements intelligent caching to prevent API rate limits and ensure lightning-fast load times.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+), Three.js
- **Backend**: Python 3.10+, Flask API
- **Integrations**: GitHub REST API, LeetCode GraphQL API

## 🏁 Getting Started

### Prerequisites
- Python 3.10+
- Git

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/rajmaheshwari3001-dev/portfolio.git
   cd portfolio
   ```

2. **Setup the Virtual Environment**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Environment Variables (Optional)**
   To increase the GitHub API rate limit, you can export a Personal Access Token:
   ```bash
   export GITHUB_TOKEN="your_personal_access_token"
   ```

5. **Run the Application**
   ```bash
   python app.py
   ```
   The application will be available at `http://localhost:5000`.
